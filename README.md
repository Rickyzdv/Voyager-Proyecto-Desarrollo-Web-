# Voyager: first prototype

First frontend prototype of **Voyager**, a travel social network, built with **React, TypeScript, Vite and Leaflet** for the Web Application Development course at Universidad Panamericana (2025).

➡️ **The complete version, with a Go backend, PostgreSQL database and Docker setup, is [Voyager 1.0](https://github.com/Rickyzdv/Voyager-1.0).**

## Running locally

```bash
npm install
npm run dev
```
